Open in Riina for Firefox

Enable Open Riina links from the browser in Riina Setup on Windows. For a developer build on macOS or Linux, register the Riina link handler first.

  1. Open about:debugging in Firefox and select This Firefox.
  2. Choose Load Temporary Add-on….
  3. Select manifest.json in the folder containing this guide.

Firefox removes temporary add-ons when it quits. Load the add-on again after restarting Firefox.

Click the toolbar button to send the current page to Riina. Right-click a page, link, video, or audio player to send that item. Use the add-on’s settings to choose a default playback action or show a menu of actions.
