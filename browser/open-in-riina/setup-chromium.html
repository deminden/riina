Open in Riina for Chrome and Edge

Enable Open Riina links from the browser in Riina Setup on Windows. For a developer build on macOS or Linux, register the Riina link handler first.

  1. Open chrome://extensions in Chrome or edge://extensions in Edge.
  2. Turn on Developer mode, then choose Load unpacked.
  3. Select the folder containing this guide and manifest.json.
  4. Pin Open in Riina from the Extensions menu for easy access.

Click the toolbar button to send the current page to Riina. Right-click a page, link, video, or audio player to send that item. Use the extension’s settings to choose a default playback action or show a menu of actions.
