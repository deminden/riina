Open in Riina for Safari

Safari setup requires Xcode and a Riina development bundle built with browser links enabled. The Safari integration is awaiting native verification.

  1. Use Apple’s Safari web extension packager with the folder containing this guide and manifest.json.
  2. Build and run the generated macOS app from Xcode.
  3. Enable Open in Riina in Safari Settings under Extensions.
