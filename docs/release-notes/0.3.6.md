# Riina 0.3.6

Riina 0.3.6 continues the Windows player and interface parity work against IINA
v1.5.0.

- Expands the plugin system with player sidebars, plugin-managed menu actions,
  ordering, file access, and broader playback/window lifecycle events.
- Adds video-backed blur beneath translucent controls and sidebars in the shared
  OpenGL presentation path.
- Improves A–B loop shortcuts and timeline markers, subtitle font previews, and
  macOS sidebar motion behavior.

The portable Windows x64 package includes the tested playback runtime and its
license notices. macOS and Linux remain in development and are not supported by
this release.
