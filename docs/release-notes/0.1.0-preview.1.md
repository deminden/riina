# riina 0.1.0-preview.1

Development milestone targeting IINA v1.5.0, with original MIT Rust source.

- Expanded playback shortcuts and observed native behavior: A–B repeat, file
  repeat, frame navigation, chapter/track navigation and timing adjustments.
- Added video aspect, rotation, flip/mirror, deinterlace and crop controls,
  including a shared crop editor and scoped feedback.
- Expanded subtitle font, size, position, color and style controls.
- Added screenshot formats, subtitle composition, preview and live General
  preferences with a folder chooser and independent file/clipboard destinations.
- Improved settings replacement integrity and clipboard capture cleanup.

Windows verification includes workspace tests, strict lint, an optimized build,
all 36 native engine integration tests, original fixture/asset hashes, and recorded
desktop checks. PNG clipboard capture has exact pixel comparisons against saved
frames. The newest temporary-folder shutdown ownership change has a filesystem
regression; rapid capture followed by application close is not yet GUI verified.

This is a source preview. It predates the current GPLv3 package route and private
release-candidate workflow. No Windows installer or portable executable was
included in this milestone; the current candidate must pass its package and
corresponding-source checks before binaries are published.

Full feature and pixel-perfect interface parity remain incomplete. macOS/Linux
application validation, calibrated HDR output, non-PNG clipboard decoding and
broader window/DPI testing remain open. Default native v210 BFF deinterlacing still
has a recorded temporal-order pixel failure; passing engine tests do not resolve
that separate oracle. See docs/status.md and docs/parity.csv for scoped evidence.
