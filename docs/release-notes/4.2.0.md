# Riina 4.2.0

<!-- A slightly more mellow milestone. See you at 4:20. -->

This Windows update improves everyday playback, Quick Settings and Music Mode.

## Quick Settings and controls

- Navigate all track lists with repeated arrows, Home/End and Page Up/Down.
  Focused rows stay visible, and language badges leave room for track names.
- Save and rename equalizer profiles with the keyboard, including Unicode names.
  First clicks on sliders work and light-theme handles remain visible.
- Correct the play triangle's optical alignment without moving the pause symbol
  or its button. Music Mode uses independent transport and window controls.
- Route configurable Control shortcuts through the framed Windows player.

## Playlists, history and window transitions

- Keep playlist rows at the available width and provide six compact footer
  actions, with further editing available in each row's context menu.
- Enter Music Mode after paused audio discovery and preserve its compact window
  size when embedded artwork is present.
- Apply Windows geometry updates in groups with the same native parent.
- Match Windows resume-file paths correctly. History accepts duration discovered
  later without resetting progress or recording another visit.
- Use neutral auxiliary-window fills in light and dark themes.

## Package and verification

The Windows 11 x64 portable package reuses the verified playback engine from
4.1.0. Its native build recipe is unchanged; the application is rebuilt from
this release's source. No separate mpv installation is required.

Release checks cover locked dependencies, formatting, strict linting, regression
tests, native playback, imports, notices, corresponding source and the extracted
application. Checksums and an exact-package report accompany the Windows ZIP.
Original Riina source is MIT; the combined package is GPLv3. Source access uses
the immutable release tag, Cargo.lock and pinned native manifests, without
duplicating native or vendored Rust source trees in the download.

Full IINA 1.5.0 parity remains in progress. Music Mode artwork still needs improved
clipping and letterboxing around the compact controls. In very small windows,
Audio can lose its scroll position after visiting Layout; Fit to Screen also
needs further work at 300% display scaling. Complete keyboard focus,
accessibility, other DPI, macOS/Linux application playback, physical audio and HDR
remain separate acceptance work. See
[current status](https://github.com/deminden/riina/blob/v4.2.0/docs/status.md).
