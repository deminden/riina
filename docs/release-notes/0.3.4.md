# Riina 0.3.4

Riina 0.3.4 continues the Windows player and interface parity work against IINA
v1.5.0.

- Adds video aspect, crop, and rotation controls with matching playback feedback.
- Improves playlist transitions, subtitle discovery and selection, and playback
  history workflows.
- Expands key-binding profile management and the Interface preferences for
  on-screen controls.
- Refines Windows native menus, title handling, window placement, and small-window
  controller layout.
- Applies the configured window-resize timing consistently during manual opens
  and automatic playlist playback.

The portable Windows x64 package includes the tested playback runtime and its
license notices. macOS and Linux remain in development and are not supported by
this release.
