# Riina 0.4.0

This release brings a substantial Windows interface and reliability update,
continuing compatibility work against IINA 1.5.0.

## Preferences that fit

- Rebuilds Subtitles settings with full-width controls, independent primary and
  secondary ASS choices, and sections that move correctly when details expand.
- Makes Audio and Network settings continuous scrolling pages. Section links and
  search reveal the same controls instead of hiding neighboring sections.
- Adds General subsection links and corrects their scroll positions. The repeat
  selector has its own row so its label stays readable.
- Fixes white-on-white controls, overlapping Utilities rows and Advanced path
  fields, truncated Windows shortcuts, and narrow auxiliary-window placement.
- Improves the font chooser's contrast, initial keyboard focus and Escape handling.
- Corrects light Quick Settings tint layering so video no longer washes out labels.
- Keeps all Quick Settings tabs reachable in narrow windows. Audio settings scroll
  together, with horizontal scrolling for equalizer bands when needed; unused
  panel input stays inside the sidebar.

## Playback and reliability

- Keeps volume changes from rebuilding the native menu and interrupting video.
- Preserves fullscreen video when playback controls appear, using the Windows
  overlay workaround verified on the development machine.
- Restores missing menu shortcut hints, including shifted punctuation, while
  retaining default aliases. Subtitle scale menu steps multiply as in IINA; speed,
  volume and delay information refreshes without rebuilding the native menu.
- Routes fullscreen Escape correctly when the framed playback host has focus.
- Merges preference edits safely across windows and preserves accepted playback
  commands in order under queue pressure.
- Strengthens regression coverage for persistence, playback lifecycle, plugin
  networking, shortcut presentation and release packaging.

The README and development documentation have been rewritten around current
behavior, downloads and remaining work. Historical visual findings are separated
from the current comparison ledger.

## Availability and limits

Windows 11 x64 is supported. The portable ZIP includes the existing playback
engine and required notices; no separate mpv installation is needed. Native and
vendored source trees are not duplicated into download assets. The release tag,
lockfile and packaged source manifest identify the corresponding sources.

Full IINA behavior and pixel parity remain in progress. macOS/Linux application
ports, HDR/color validation, wider hardware/DPI coverage, localization and complete
plugin compatibility remain open. See [current status](https://github.com/deminden/riina/blob/v0.4.0/docs/status.md)
for scope and verification records.
