# Riina 0.5.0

This source release resumes Riina's 0.x version series. Build instructions are
in the [source tree](https://github.com/deminden/riina/tree/v0.5.0#build-from-source).
The existing Windows installer and portable package are available from the
[4.2.1 Windows release](https://github.com/deminden/riina/releases/tag/v4.2.1).

## Opening and playback

- File opens and playlist transitions wait for the decoder to prepare playback.
  Pause When Open and explicit play or pause requests apply to the new media.
- Unicode stream URLs work in Open URL, startup and desktop transfers while
  existing escapes and signed query strings keep their spelling. Internet
  shortcuts and their target URLs share duplicate-player detection.
- Mixed drops open the playable files and leave subtitle discovery to the
  player. A subtitle-only drop adds or reloads tracks on the receiving file.
- Open URL can cancel a stalled request or retry a failed stream. Playlist
  changes retire stale loading and discovery work.

## Development and ports

- Focused checks select affected crates and keep native playback tests in
  groups. The [development guide](https://github.com/deminden/riina/blob/v0.5.0/docs/development.md)
  explains the fast check and the full workspace gate.
- The [verification record](https://github.com/deminden/riina/blob/v0.5.0/docs/verification.md)
  reports Windows and isolated Linux desktop coverage. Native macOS,
  matched visual comparisons and additional hardware checks remain open.

See the [current status](https://github.com/deminden/riina/blob/v0.5.0/docs/status.md)
and [implementation plan](https://github.com/deminden/riina/blob/v0.5.0/docs/implementation-plan.md)
for the remaining work.
