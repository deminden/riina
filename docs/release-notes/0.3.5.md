# Riina 0.3.5

Riina 0.3.5 continues the Windows player and interface parity work against IINA
v1.5.0.

- Adds Assrt and Shooter.cn to online subtitle search, with provider-specific
  credentials and bounded response handling.
- Expands playback history browsing, search, and organization.
- Extends plugin package file access and runtime lifecycle handling.
- Improves playlist handoffs, automatic window sizing, and compact-player
  behavior during media changes.
- Adds preference navigation and subtitle-language controls.

The portable Windows x64 package includes the tested playback runtime and its
license notices. macOS and Linux remain in development and are not supported by
this release.
