# Riina 0.3.8

Riina 0.3.8 continues player and interface parity work against IINA v1.5.0.

- Adds IINA's primary and alternative keyboard actions, including frame stepping,
  subtitle seeking, audio/subtitle delay, subtitle scaling, and online subtitle
  search.
- Improves Audio Quick Settings with a labeled equalizer scale and profile
  management from the preset selector.
- Refines Windows playback controls for smaller windows and updates Picture in
  Picture resizing, playlist actions, and native Help menu links.
- Adds Windows surface-material options to the Utilities and playback interface.

The Windows x64 portable package includes its playback runtime and license
notices. macOS and Linux remain in development and are not supported by this
release.
