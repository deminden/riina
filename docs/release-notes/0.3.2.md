## What's new since 0.3.0

- Timeline thumbnail previews for local videos.
- Automatic subtitle discovery and matching, plus OpenSubtitles search and download using your own OpenSubtitles key.
- A fuller Music Mode with album art, track details, playlist visibility controls, and a compact volume control.
- More keyboard shortcut presets and expanded custom-profile editing and management.
- An option to add other media files from the same folder to the playlist automatically.
- More playback feedback for volume, mute, subtitles, and track changes, along with refined mouse-wheel seeking and volume controls.
- Installation and update controls for supported plugins, including installation from GitHub.
