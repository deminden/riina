# Riina 0.5.1

Riina 0.5.1 includes a Windows 11 x64 installer and portable package. It brings
the playback changes from the [0.5.0 source release](https://github.com/deminden/riina/releases/tag/v0.5.0)
to Windows downloads.

- Update the HTTPS client and bundled certificate roots. This closes the
  certificate-trust issue affecting update checks, plugin downloads and online
  subtitles. Stable dependency updates also refresh the URL, ZIP and UI libraries.
- Use the verified playback engine with the Matroska field-order fix so interlaced
  video carries the field order signaled by the container when FFmpeg needs it.

Both packages include native license notices and a source manifest. Rebuild
instructions and the pinned source inputs are in the
[source access guide](https://github.com/deminden/riina/blob/v0.5.1/docs/SOURCE-ACCESS.md).
