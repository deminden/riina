## What's new since 0.3.2

- A configurable on-screen controller with playback speed, transport, volume, plugin, Picture in Picture, playlist and chapters, and Quick Settings actions.
- Quick Settings access from the playback controller, plus expanded playback, layout, and OSC preferences.
- IINA-ordered application menus with platform-specific shortcut labels and more wired playback, video, audio, subtitle, file, and plugin actions.
- Playback history and recent-media workflows, playlist metadata and export, and improved file selection and opening.
- Interactive crop and delogo selection, a video-filter window with saved presets, and expanded audio/video filter controls.
- A larger plugin runtime surface, including permission-checked network requests, downloads, XML-RPC, track state, and window controls.
- Improved window sizing, resize handling, subtitle controls, key-binding preferences, and portable platform adapters.

Windows 11 x64 remains the supported application target. macOS and Linux port work is in progress and is not yet declared supported.
