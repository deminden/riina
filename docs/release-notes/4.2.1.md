# Riina 4.2.1

This Windows update fixes washed-out video and improves playback reliability.

## Video and controls

- Remove the Windows tint from the transparent controls window, which lifted
  blacks and dulled HDR highlights across the video.
- Keep native HDR conversion in the Windows output color space instead of
  applying an automatic SDR display profile. SDR media retains the ICC preference.
- Refresh output when Windows HDR changes or the player moves between displays,
  including during paused playback. Preserve the current video's HDR preference.
- Hide the pointer after playback controls become idle and restore it on activity.
- Keep native menu state current and preserve playback when fullscreen requests
  cannot be completed.

## Reliability

- Improve configurable shortcut dispatch, including encoded special keys and
  duplicate bindings.
- Preserve concurrent preference changes and prevent different plugin identifiers
  from sharing a private storage directory.
- Serialize plugin permission updates and tighten plugin file and network handling.
- Improve playback ownership, resume handling, capture coordination and shutdown.

## Package and verification

The Windows 11 x64 Setup EXE and portable ZIP include the same application and
playback engine. This release rebuilds the application and reuses the verified
4.2.0 engine with an unchanged native build recipe, runtime hashes and notices.
No separate mpv installation is required.

Local desktop checks compared the reported HDR10 movie against VLC and switched
Windows HDR off and on. Color-patch checks confirm that showing the controls no
longer changes the underlying video. Desktop captures cannot establish calibrated
HDR luminance or identical tone mapping between players. Exact-package build,
playback, installer and source-access reports accompany the published downloads.

Original Riina source remains MIT; the combined application package is GPLv3.
Full IINA 1.5.0 feature and visual parity remain in progress. macOS/Linux application
ports, wider display/GPU coverage and physical audio/HDR calibration remain separate
acceptance work. See [current status](https://github.com/deminden/riina/blob/v4.2.1/docs/status.md).
