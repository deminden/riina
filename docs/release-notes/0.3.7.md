# Riina 0.3.7

Riina 0.3.7 continues Windows player and interface parity work against IINA
v1.5.0.

- Enables the Help menu links for the project guide, latest release, repository,
  and README in both the shared and Windows-native menus.
- Shows the active new Settings window mode in the Help menu, matching the
  captured IINA menu state.
- Makes the plugin-sidebar placement test independent of a graphics driver so
  Windows CI can run it on a headless runner.

The Windows x64 portable package includes its playback runtime and license
notices. macOS and Linux remain in development and are not supported by this
release.
