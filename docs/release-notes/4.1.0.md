# Riina 4.1.0

This Windows update improves Quick Settings input, keyboard navigation and player
layout. The version 4.1.0 was explicitly selected for this release, following
0.4.0; it does not indicate complete IINA parity.

## Quick Settings

- Preserve audio/subtitle delay and speed drafts while playback updates arrive
  or transport controls hide. Return and Tab submit once; Escape cancels the edit.
- Navigate categories with arrows and Home/End through one keyboard stop.
  Selected categories, track rows and Layout controls expose clearer focus.
- Keep narrow Layout pages scrollable at usable proportions, with full-sized
  controls and controller-choice tiles.
- Keep Dark, Light and Auto selections and focus outlines inside their rail.
- Align Compact Interface and related symbols with labels and switches. Center
  controller previews, choice tiles and section separators.

## Playback controls and Windows menus

- Center Play/Pause independently of volume visibility and toolbar customization.
- Retain separate, reachable actions in small player windows; use a compact packed
  row when symmetric spacing cannot fit.
- Route system-menu input through the framed player window and repair a consumed
  Alt release after menu mode ends. Intentional Alt shortcuts remain available.
- Preserve normal Windows Escape behavior: closing a dropdown can leave menu-bar
  navigation active until a second Escape.

## Package and verification

The Windows 11 x64 portable ZIP includes the verified playback engine reused from
0.4.0. The application is rebuilt from this release's exact source; the engine's
native recipe and manifests are unchanged. No separate mpv installation is needed.

The release process checks locked dependencies, regression tests, native playback,
imports, notices and corresponding source, then runs the extracted application.
Checksums and the exact-package verification report accompany the binary.

Original source remains MIT; the combined package is distributed under GPLv3
terms with dependency notices. Native and vendored Rust source trees are not
duplicated in the download. The immutable tag, Cargo.lock, packaged source
manifest and build instructions identify its source inputs.

Full IINA 1.5.0 behavior and visual parity remain in progress. macOS/Linux
application ports, HDR/color validation, other display scales and hardware,
localization and complete plugin compatibility remain open. See
[current status](https://github.com/deminden/riina/blob/v4.1.0/docs/status.md).
