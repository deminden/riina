# Player control icons

Original riina geometric SVGs, MIT under the root LICENSE. No external artwork
was traced or copied. White artwork is tinted by the shared UI for enabled and
disabled states. The 24-unit viewbox is rendered in a 17-point control box.
Shapes are provisional until comparison against matching IINA captures.

SVG files use LF line endings. Record hashes of those canonical bytes, then run
`python scripts/check-assets.py --staged` after staging assets and the manifest.
This checks publication bytes even if a Windows editor wrote local CRLF files.
